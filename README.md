# GoldenBoy 개발 블로그

`goldenboy.co.kr`은 제가 직접 개발하고 운영 중인 개인 개발 블로그입니다.

저의 본래 전문 분야는 **SLAM / Localization / Robotics Software**입니다.
로봇이 실제 공간을 인식하고, 지도를 만들고, 자신의 위치를 추정하는 기술에 관심을 가지고 개발해왔습니다.

하지만 오래전부터 단순히 코드를 작성하는 것에서 끝나는 것이 아니라,
제가 공부하고 개발한 내용을 직접 정리하고, 기록하고, 보여줄 수 있는 **개발 블로그를 직접 만들고 싶다**는 목표가 있었습니다.

그래서 기존 블로그 플랫폼을 사용하는 대신, 직접 웹 서비스를 만들기로 했습니다.

## Why Flutter?

이 프로젝트에서는 프론트엔드 기술로 **Flutter**를 선택했습니다.

Flutter는 하나의 코드베이스로 Web, Mobile, Desktop 등 다양한 플랫폼에 대응할 수 있는 멀티플랫폼 프레임워크입니다.
저는 개발 블로그를 단순한 웹페이지가 아니라, 앞으로 다양한 형태로 확장 가능한 개인 개발 플랫폼으로 만들고 싶었습니다.

그렇기 때문에 Flutter를 사용해 다음과 같은 방향을 목표로 했습니다.

* Web 기반 개발 블로그 운영
* 프로젝트 포트폴리오 페이지 구성
* SLAM / Robotics 개발 기록 정리
* 향후 모바일/데스크톱 확장 가능성 확보
* 직접 만든 제품, 3D 모델, 로봇 프로젝트 소개 및 판매 페이지 확장

## What I Built

이 프로젝트는 단순한 정적 페이지가 아니라, 제가 직접 설계하고 운영하는 개인 개발 서비스입니다.

현재 `goldenboy.co.kr`을 통해 다음과 같은 내용을 관리하고 있습니다.

* SLAM 개발 기록
* Robotics 프로젝트 정리
* 개발 블로그 게시글
* 포트폴리오 페이지
* 개인 프로젝트 소개
* 향후 Shop / Product 페이지 확장 계획

블로그를 직접 개발하면서 프론트엔드 UI 구성, 라우팅, 콘텐츠 구조화, 배포, 서버 운영, 도메인 연결 등 실제 서비스를 운영하는 데 필요한 과정을 경험했습니다.

## Tech Stack

이 프로젝트는 다음 기술을 기반으로 구성되어 있습니다.

* Flutter Web
* Dart
* Node.js / Express
* Markdown 기반 콘텐츠 관리
* 개인 서버 / NAS 기반 배포 환경
* Custom domain: `goldenboy.co.kr`

## Why This Project Matters

저는 SLAM 개발자입니다.
하지만 좋은 개발자는 자신의 전문 분야만 이해하는 것이 아니라, 자신이 만든 결과물을 사용자에게 전달하는 방식까지 고민해야 한다고 생각합니다.

`goldenboy.co.kr`은 그런 관점에서 시작한 프로젝트입니다.

단순히 취업을 위한 포트폴리오가 아니라,
제가 실제로 개발하고, 배포하고, 운영하며, 계속 개선하고 있는 개인 서비스입니다.

이 프로젝트를 통해 저는 다음을 보여주고 싶었습니다.

* 개발 내용을 꾸준히 기록하는 습관
* 직접 서비스를 만들고 운영하는 실행력
* 새로운 기술을 학습하고 적용하는 태도
* SLAM / Robotics 개발자로서의 성장 과정
* 문제를 발견하고 직접 해결하려는 개발자적 성향

## Future Plan

앞으로 `goldenboy.co.kr`은 단순한 개발 블로그를 넘어,
제가 만든 로봇 프로젝트와 3D 모델, 개발 도구, 실험 결과물을 소개하는 개인 개발 플랫폼으로 확장할 계획입니다.

특히 다음과 같은 방향을 준비하고 있습니다.

* SLAM 프로젝트 상세 기록
* GoldenSLAM 개발 과정 정리
* Pet Robot / GoldenBot 제작기
* 3D 모델 및 로봇 부품 소개
* Digital Download / Shop 페이지
* 개발자 포트폴리오 허브

## Summary

`goldenboy.co.kr`은 제가 직접 만든 개발 블로그이자,
제가 개발자로서 어떤 문제를 고민하고, 어떤 방식으로 성장하고 있는지를 보여주는 공간입니다.

SLAM 개발자로서의 전문성을 기반으로 하되,
웹 서비스 개발, 배포, 운영, 콘텐츠 관리까지 직접 경험하며
개발자로서의 폭을 넓히기 위해 만든 프로젝트입니다.
