# GoldenBoy 개발 블로그

[goldenboy.co.kr](https://goldenboy.co.kr)은 제가 직접 만들고 운영하고 있는 개인 개발 블로그입니다.

저는 원래 SLAM / Localization / Robotics Software 쪽을 주로 해왔습니다.
로봇이 실제 공간에서 움직이려면 지도를 만들고, 자기 위치를 알고, 센서 데이터를 해석해야 하는데, 저는 이런 부분을 계속 공부하고 개발해왔습니다.

그런데 언젠가부터 단순히 코드를 작성하는 것에서 끝내지 않고,
제가 개발한 내용과 공부한 과정을 직접 정리해서 보여줄 수 있는 공간이 필요하다고 생각했습니다.

그래서 기존 블로그 플랫폼을 쓰는 대신, 직접 개발 블로그를 만들어보기로 했습니다.
그렇게 시작한 프로젝트가 **goldenboy.co.kr**입니다.

## 왜 직접 만들었나?

솔직히 말하면, 블로그는 그냥 티스토리나 Velog 같은 플랫폼을 써도 됩니다.
하지만 저는 개발자로서 제 기록을 남기는 공간도 직접 만들어보고 싶었습니다.

단순히 글만 올리는 블로그가 아니라,

* 제가 어떤 프로젝트를 해왔는지
* 어떤 문제를 만났고 어떻게 해결했는지
* SLAM이나 로봇 개발을 어떻게 공부하고 있는지
* 앞으로 어떤 방향으로 개발을 이어갈 것인지

이런 것들을 제 방식대로 정리할 수 있는 개인 개발 플랫폼을 만들고 싶었습니다.

그래서 Flutter Web을 사용해 프론트엔드를 만들고,
Node.js / Express 기반으로 서버를 구성해서 직접 운영하고 있습니다.

## 왜 Flutter를 썼나?

Flutter를 선택한 이유는 단순합니다.
하나의 코드베이스로 Web, Mobile, Desktop까지 확장할 수 있다는 점이 마음에 들었습니다.

처음에는 개발 블로그로 시작했지만, 나중에는 단순한 웹페이지를 넘어서
제가 만든 로봇 프로젝트, SLAM 개발 기록, 포트폴리오, 실험 결과물들을 한 곳에 모으는 플랫폼으로 키우고 싶었습니다.

그래서 처음부터 확장성을 생각해서 Flutter를 선택했습니다.

현재는 웹 기반 블로그로 운영하고 있지만, 구조적으로는 나중에 모바일이나 데스크톱 쪽으로도 확장할 수 있도록 생각하고 있습니다.

## 현재 사이트에서 다루는 내용

goldenboy.co.kr에는 제가 직접 개발하고 있는 프로젝트와 공부 내용을 정리하고 있습니다.

주로 다루는 내용은 다음과 같습니다.

* SLAM 개발 기록
* Localization / Robotics 관련 공부 내용
* GoldenSLAM 개발 과정
* 로봇 프로젝트 제작 기록
* 개인 포트폴리오
* 개발 중 만난 문제와 해결 과정
* 직접 만든 프로젝트 소개

특히 SLAM 관련해서는 단순히 “이런 기술을 써봤다” 정도가 아니라,
제가 실제로 코드를 만지고, 구조를 바꾸고, 실패하고, 다시 시도하는 과정까지 기록하려고 합니다.

## 이 사이트는 수익 목적이 아닙니다

현재 goldenboy.co.kr은 수익화를 목적으로 운영하고 있지 않습니다.

사이트 안에서 결제나 판매, 쇼핑몰 구조와 관련된 기능을 검토한 적은 있지만,
그것은 실제 상업 운영을 위한 목적이라기보다는
서비스 확장 가능성을 실험하고, 웹 서비스를 어떻게 설계할 수 있는지 공부하기 위한 목적에 가깝습니다.

지금 이 사이트의 가장 큰 목적은
제가 직접 개발하고, 배포하고, 운영하고 있는 프로젝트를 보여주는 것입니다.

## 사용한 기술

현재 이 블로그는 다음 기술들을 기반으로 구성되어 있습니다.

* Flutter Web
* Dart
* Node.js / Express
* Markdown 기반 콘텐츠 관리
* 개인 서버 / NAS 기반 배포 환경
* Custom Domain: goldenboy.co.kr

직접 만들면서 프론트엔드 화면 구성, 라우팅, 콘텐츠 구조화, 서버 운영, 도메인 연결, 배포 과정 등을 경험했습니다.

## 앞으로의 방향

앞으로 goldenboy.co.kr은 단순한 개발 블로그에서 끝나지 않고,
제가 만들고 있는 프로젝트들을 정리하는 개인 개발 플랫폼으로 확장해나갈 생각입니다.

특히 다음과 같은 내용을 계속 추가할 계획입니다.

* GoldenSLAM 개발 기록
* FAST-LIO2 기반 SLAM 분석 및 개선 과정
* Keyframe / Backend / Optimization 추가 과정
* Pet Robot / GoldenBot 제작기
* 로봇 외형 설계 및 3D 모델링 기록
* 개발 도구와 실험 결과물 정리
* SLAM / Robotics 포트폴리오 허브

저는 이 사이트를 통해 단순히 “블로그를 만들었다”는 것을 보여주고 싶은 것이 아닙니다.

제가 개발을 어떻게 바라보고 있는지,
문제를 만나면 어떻게 파고드는지,
그리고 개발자로서 어떤 방향으로 성장하고 있는지를 보여주고 싶습니다.

## 정리

goldenboy.co.kr은 제가 직접 개발하고 운영하는 개인 개발 블로그입니다.

수익화를 위한 쇼핑몰이 아니라,
제가 공부하고 개발한 내용을 기록하고, 프로젝트를 정리하고, 개발자로서의 성장 과정을 보여주기 위한 공간입니다.

SLAM 개발자로서의 전문성을 기반으로,
웹 서비스 개발과 운영까지 직접 경험하면서
제가 만든 결과물을 더 잘 보여줄 수 있는 개발자가 되는 것이 이 프로젝트의 목표입니다.
